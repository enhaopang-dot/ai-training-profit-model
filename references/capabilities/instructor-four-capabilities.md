# 讲师四项核心能力模型（instructor-four-capabilities）

## R — 原文规则

> "1. AI 技术能力（入场券）……2. 业务理解能力……3. 授课表达能力……练习方法——口述录音成文字稿，反复练习迭代。4. 个人 IP 能力：要长期稳定接高客单价单，需要市场持续看见你。"
> ——原文 §8 四项核心能力（p49 讲师四项核心能力清单 / f38 讲师四项核心能力模型）

规则本体：讲师能力栈 = 四格——AI 技术能力（入场券，深入了解主流工具且持续学习，团队可分工各专一项）、业务理解能力（不必行业专家，但要知道目标客户的核心需求）、授课表达能力（带明确练习法：口述录音成文字稿反复迭代）、个人 IP 能力（长期稳定接高客单的前提 = 市场持续看见你）。

## I — 释义

本模型把"我要不要当讲师/我能不能涨价"的模糊纠结转成四格可查的短板清单。四格不是并列平均分：AI 技术是入场券——不过关连牌桌都上不去；个人 IP 是天花板项——决定能否长期稳定接高客单；中间两格（业务理解、授课表达）决定交付质量但不构成壁垒。四格与供给四层漏斗（u03）前四层一一对应：缺哪一层就被卡在哪一层，补上一层才配涨一级价。

最值得注意的细节是第三格自带练习法（口述录音转文字稿反复迭代）——这是全书少有的把"软能力"落成可执行动作的条目，不是口号。第二格的边界同样明确：懂客户核心需求即可，行业经验在客户那边，讲师不背"懂行业"的锅（与 u42 心态坑"怕学员更懂"互证）。

适用前提：考虑转型或已在岗的讲师做自我诊断。不适用：团队招聘时的他人评估（原文按自我修炼场景给出）。

## A1 — 应用示例

本单元无绑定的亲历正例（merged-units 支撑材料为 x06/x15 两条反例），按"最贴近者"原则示范：

- 反例 x06（§8 心态四坑 1，bound 至本单元）：讲师因不懂客户行业（制造/医疗/法律）而心虚，不敢接行业单，或被学员行业问题问倒后自我怀疑。对照执行：四格中"业务理解"格的自查问题正是解药——"是否知道目标客户的核心需求？"合格线不是成为行业专家，而是听得懂对方说什么；行业问题课堂上交给学员。
- 反例 x15（§2 AI工具迭代 + §8 双轨学习法，bound 至本单元）：靠存量课件吃老本，不跟进新工具；课堂上被学员用新工具问倒，"专业可信"人设崩塌，复购与转介绍清零。对照执行：x15 击穿的是第一格"AI 技术能力（入场券）"——它不像学历一次考取终身有效，需要持续续费（机制走 u41 双轨学习法）。

## A2 — 触发场景

1. 在考虑转型 AI 培训讲师，纠结"我够不够格"。
2. 接课接了一阵子，客单价涨不上去，不知道短板在哪。
3. 只磕技术不做 IP，或只运营 IP 技术跟不上，想校准发力点。
4. 想找一项能力的具体练习方法（如授课表达怎么练）。

语言信号："想当 AI 讲师需要哪些能力""我能不能做培训讲师""讲师能力自查""客单价为什么上不去""授课表达怎么练""做讲师最大的短板是什么"。

英文 trigger patterns: "instructor capability self-assessment", "what skills does an AI trainer need", "AI training career readiness", "why can't I charge higher rates", "teaching skills practice method".

相邻区分：与 u42 心态四坑区分——u42 管掉进坑后的认知重构，本卡管事前能力诊断；与 u41 双轨学习法区分——u41 管第一格能力的日常续费机制，本卡管四格整体定位。

## E — 执行契约

输入契约：转型者当前背景（技术/业务/表达/IP 四方面的经历事实）。缺失任一方面的真实信息时应先引导用户自述，不能替其脑补评分。

四格自查表（逐项回答 → 结论）：

1. AI 技术能力（入场券）：是否深入了解主流工具并持续学习？→ 不合格先补此项，其余三格暂缓投入。
2. 业务理解能力：是否知道目标客户（选定行业）的核心需求？→ 不必行业专家，标准是"听得懂对方说什么"。
3. 授课表达能力：是否做过"口述录音转文字稿"的反复练习？→ 未做过即按原文练习法启动第一轮。
4. 个人 IP 能力：市场是否持续看见你（公众号/视频号/小红书有稳定输出）？→ 此项是长期高客单的前提，投入不足要显性写进计划。

完成标准：四格各有"达标/短板"结论 + 最短板一项 + 对应补差动作（引用原文给的练习法或指向 u41 机制）。

输出契约：四格自查结论表（格名/自查问题/结论/补差动作）+ 最短板定位。四格全过且无最短板时输出"无显著短板，优先投入 IP 格"（按原文"长期稳定接高客单的前提"逻辑）。

## B — 边界

- 反场景：已经是成熟讲师做团队招聘/他人评估，本卡按自我修炼设计，不作他评量表；课中具体动作走 u30-u38。
- 原文缺口（verified gaps）：四能力的合格线原文未量化（"深入了解主流工具"具体到几个工具/什么深度，原文未给，自查时不可虚构及格线）；团队"各专一项"的解法对个人讲师不可直接用（x29 适用边界）——个人讲师四格全靠自己，自查结论需按单人容量打折扣。
- 失败模式（x06/x15 反向印证）：把"懂行业"误当交付责任而弃单；把入场券当终身有效而吃老本。
- 相邻易混淆：与 u03 供给四层漏斗是同一结构的自视版本——u03 看市场竞争者分布，本卡看自己卡在哪个能力层。
