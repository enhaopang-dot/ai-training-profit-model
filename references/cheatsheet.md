# 决策规则速查 — 我做了50场AI企业培训终于搞清这门生意的赚钱模型（飞书文档 2026-05-18 修改版）

| 能力 | 一句话规则 |
|---|---|
| 市场真实性四信号验证法 | 不从宏观报告拍板，用渗透率落差/动力错位/付款人使用人分离/供给稀缺四信号验证市场是否真实存在 |
| 双受众设计模型（买单人vs听课人） | B 端培训必须同时满足两头：学员当场快速上手＋买单人看到可量化变化，缺一即复购链断裂 |
| 供给四层漏斗与信任采购 | 懂AI→能讲课→懂行业→有可信度逐层过滤，企业采购培训采购的是信任，竞争壁垒建在漏斗顶层 |
| 需求两极分布规律 | 需求集中在两个极端：重度依赖电脑的行业（ROI最直观）与远离互联网的传统行业（为成果付费意愿强），中间态需求最弱 |
| 城市分层进入框架 | 先分层（新一线/二线是最大蓝海）再过四条件（产业密集/交付稀缺/种子渠道/区位可上可下）决定进入哪座城 |
| 定位升级：教工具→建工作方法 | 知识免费化下定位上移：从教工具升级为帮企业建立 AI 时代工作方法——筛选工具/建认知体系/嵌进业务流程/促使员工用起来 |
| 产品四层递进与收入三层漏斗 | 公开课→标准内训→定制工作坊→年框四层递进，培训是信任入口、标准化产品做规模、定制服务赚高利润，前端定价为筛后端客户 |
| LTV五步升级路径 | 单客户五步升级：公开课→首单内训→定制工作坊（客单3倍）→工作流定制（持续收入）→年框，LTV≥首课酬20倍 |
| 定价区间表与取值规则 | 半天8千-1.5万/全天1.5-3万/两天3-6万/年框10-30万；基础取下限定制取上限、一线浮20-30%，2026-05行情须本地复核 |
| 报价四原则与降价处理 | 先摸背景再首报留空间；异议砍服务不砍价；预算不够唯一出口是转介绍，一次降价即成渠道永久基准价 |
| 成本核算与隐性成本摊入 | 显性七项求和后摊入隐性20-30%（总成本=显性×1.2~1.3），差旅占课酬15-25%红线校验，输出最低可接受价 |
| 自用系统"脱壳"产品化流程 | 清掉个人内容保留框架/模板/流程/SOP，包装通用版引流，再衍生行业定制版+培训+3个月陪跑，边际成本近零的第二收入曲线 |
| 获客渠道组合五渠配比 | 用自家订单来源对照五渠基准（40/20/15/15/10）诊断集中度风险，定补强优先级。 |
| 公开课演讲三关键 | 大型公开课三段式：数据开场抓注意力、中段现场实操（禁用截图视频）、结尾钩子+资料带走。 |
| 沙龙深度转化设计 | 沙龙=20 人以内深度信任场：控人数、茶歇、充分互动、垂直行业专场；转化率约 2-3 倍但触达少。 |
| 投放获客ROI核算 | 单均获客成本=单线索成本×成单率倒数；单单毛利覆盖即持续，覆盖不住就停或改三件套。 |
| 组局官渠道机制 | 跨城扩张找当地组局官：四要求筛选、获客组织与内容交付分工、按成本承担比例分成。 |
| 转介绍激活机制 | 转介绍靠交付驱动：主池=宣导会听众，不搞复杂激励，成交后给推荐人实质感谢。 |
| 自媒体IP精准度规则 | B 端 IP 要 100 个精准企业客户觉得靠谱，不要 100 万粉；内容聚焦真实案例/行业应用/实操经验。 |
| B端谈单节奏管理 | B 端周期 2 周~半年，两三周没消息≠凉了；多线并行不押注，焦虑的解法是加线索不是催单。 |
| 不对口客户放弃/转介绍决策 | 需求超出优势范围或预算<报价 1/3 的单：放弃或转介绍给合作讲师，不硬接、绝不降价。 |
| 讲师简介信任标签组合 | 简介按受众配五类可验证标签：技能认证给政企看、云认证给技术看、企业顾问给老板看；组合大于单标签。 |
| 售前四看筛选决策 | 售前四看定顺序：看预算（认知不足可教育/真没钱别勉强）、看决策链、看匹配度（做不了转介绍）、看时间线（以后再说=伪需求）。 |
| 售前需求调研流程 | 售前调研两路并行：问卷问题具体化+选择题优先（字段=目标/人数/岗位构成/时长预算），加学员微信深调，讲师用 AI 预研行业场景。 |
| 方案书七要素 | 方案书=产品详情页，七要素缺一不专业，价值点≥5条是硬指标 |
| 合同四要点清单 | 合同四要点锁死付款/范围/知识产权/取消四个纠纷口 |
| 课程体系模块化与定制三调整 | 通用模块复用+定制只调20%，三调整适配行业与岗位 |
| 课件制作五步流程 | 知识库驱动的五步课件流水线，2-5天压到1-2天 |
| 课件动态调整机制 | 课件双轨调整：现场随学员反应，长期随工具迭代 |
| 课前SOP五件套 | 课前五件套全勾才算就绪，翻车预防清单化 |
| 开场三问现场校准法 | 开场三问摸底，先让所有人跟上再逐步加深 |
| 高光时刻设计机制 | wow瞬间是课前设计的实操环节，不是即兴亮点 |
| 实操进度时间盒控制 | 实操设时限到点即切，落后者课后凭手册补齐 |
| 获得感设计与成功判据 | 每人带一个自制成品走，学员晒成果=培训成功 |
| 埋钩子需求激发机制 | 课中展示超范围应用，让客户主动开口要下一单 |
| 企业类型交付差异矩阵 | 三类企业三轴调整（深度/用词/着装），政企先查敏感词 |
| 现场翻车排障路径 | 现场翻车三层应对——即时淡定承接（情绪稳定本身是信任来源）、当天补救修复材料发学员、复盘核对课前SOP |
| 课后跟进与素材沉淀 | 课后四动作（调查表/拍成果/建群/回访）+ 素材一份四用途复用（留念/HR汇报/传播/新客案例） |
| 冷启动免费分享路径 | 冷启动只做免费公开分享（朋友圈/社群/沙龙）绝不免费企业内训；首单从存量信任来，保守报价换案例背书 |
| 讲师四项核心能力模型 | 讲师能力栈四格自查——AI技术（入场券）/业务理解（懂需求即可）/授课表达（口述录音迭代）/个人IP（高客单前提） |
| 双轨学习法 | 三端并行学习——技术端每周实测新工具/业务端每单沉淀行业场景库/实战端以教促学 |
| 心态四坑应对框架 | 四坑认知重构——怕学员更懂→比较优势/准备过度→边际收益/报价不自信→定价即定位/长周期焦虑→组合思维 |
| 个人vs团队模式决策 | 模式判据=目标函数——赚快钱/高利润率留个人；吃后端 LTV 做可持续生意则团队是必要的（8人分工为参考样板） |
| 复购路径与年框设计 | 复购路径预设——标准内训→定制工作坊（3倍客单）→延伸服务四类→年框咨询五项服务，需求由客户主动提出不硬推 |
| 城市扩展节奏框架 | 两条节奏纪律——先跑通再扩张（不同时在多城铺开）+ 每新城市第一场必免费沙龙/公开课打开圈层 |
| 职业底线三铁律 | 三铁律——不私下挖客户（渠道客户绝不绕签）/不过度承诺（承诺必兑现）/不随意降价（一次降价=该渠道永久基准价） |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
